# Favicon & Logo Setup Guide for Energy Talks Middle East

## Overview
To make your logo appear in Google search results and browser tabs instead of the generic globe icon, you need to create and upload favicon files.

## Required Files

You need to create the following image files and place them in the `assets/images/` folder:

### 1. **favicon.png** (Main favicon)
- Size: 48x48 pixels or 64x64 pixels
- Format: PNG with transparent background
- Content: Your "ET" logo or DAS & Partners logo

### 2. **favicon-32x32.png**
- Size: 32x32 pixels
- Format: PNG
- Content: Smaller version of your logo

### 3. **favicon-16x16.png**
- Size: 16x16 pixels
- Format: PNG
- Content: Smallest version of your logo

### 4. **apple-touch-icon.png**
- Size: 180x180 pixels
- Format: PNG
- Content: Logo for iOS devices

### 5. **logo.svg**
- Format: SVG (vector)
- Content: Your full logo in vector format

### 6. **logo-social.png** (For social media & search results)
- Size: 1200x630 pixels
- Format: PNG or JPG
- Content: Your logo with company name and tagline
- Background: Professional looking (white or branded color)
- This is what appears in Google Search results and when shared on social media

## How to Create These Files

### Option 1: Using Online Tools (Easiest)
1. Visit https://realfavicongenerator.net/
2. Upload your logo (preferably a square PNG or SVG)
3. Download the generated favicon package
4. Extract and copy all files to `assets/images/` folder

### Option 2: Using Design Software
1. Open your logo in Photoshop, GIMP, or Canva
2. Resize to each required dimension
3. Export as PNG with transparent background
4. Save files with the exact names listed above

### Option 3: Using DAS & Partners Logo
If you have your DAS & Partners company logo:
1. Use the logo file
2. Create square versions at different sizes
3. For the social media image (1200x630), create a banner with:
   - Logo
   - Company name: "DAS and Partners Engineering Consultancy"
   - Tagline: "Top Engineering Firm in UAE, Dubai, Sharjah, Abu Dhabi"

## After Creating the Files

1. Upload all files to: `EnergyTalks/assets/images/`
2. Test your favicon:
   - Open your website in a browser
   - Check if the logo appears in the browser tab
3. Submit to Google Search Console:
   - Go to https://search.google.com/search-console
   - Request re-indexing of your homepage

## For Google Search Results

The most important file is **logo-social.png** (1200x630). This is what appears in Google search results. Make sure it includes:

- Your logo prominently displayed
- Company name
- Key service information
- Clean, professional design
- High contrast for readability
